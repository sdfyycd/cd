疾病概览与病理生理

急性肺栓塞（PE）是发病率、致死率和误诊率均较高的心血管急症。了解其致死机制是有效救治的基石。

☠️

致死率排名

第 3 位

继心肌梗死和脑卒中之后，最常见的心血管死亡原因。

🩸

疾病本质

VTE 连续体

深静脉血栓（DVT）和PE是静脉血栓栓塞症（VTE）在不同部位的表现。

⚠️

临床特点

高误诊率

起病隐匿，临床表现被称为“伟大的伪装者”。

🫀 致命核心：急性右心衰竭机制

临床表现与危险因素

识别高危人群是预防和诊断的第一步。PE 临床表现缺乏特异性，但存在强相关的诱发因素。

高危险因素 (OR > 10)

强相关易患因素分析，提示极高的血栓发生概率。

典型临床症状

“伟大的伪装者”：症状多样，无咯血不代表无栓塞。

🚨 红色警报：

如果患者出现晕厥，往往提示大面积 PE 征象，可能是高危 PE 的首发症状！

诊断路径与可能性评分

诊断的核心在于“先分层、后检查”。不要直接进行影像学检查，应先进行临床可能性评估。

诊断路径决策

血流动力学稳定路径：

  1. 进行 Wells 或 Geneva 评分评估临床可能性。
  2. 若可能性低/中度，检测 D-二聚体。
    ※ D-二聚体是排除利器。>50岁者切点为 年龄×10 μg/L。阴性基本排除 PE。
  3. 若可能性大，或 D-二聚体阳性，行 CT 肺动脉造影 (CTPA) 确诊。
    ※ CTPA 为确诊金标准。发现段及以上充盈缺损即可确诊。

血流动力学不稳定路径 (高危)：

患者存在心原性休克或持续性低血压 (SBP < 90mmHg 持续>15分)。

床旁超声心动图 ➡ 发现右心负荷过重

若患者状态允许，则行 CTPA 确诊；
若无法安全转运，直接按高危 PE 启动救治（再灌注）！

💡

D-二聚体 与 CTPA 的核心定位

D-二聚体 负责“排雷”：极高敏感性，阴性即可排除稳定患者的 PE 风险，减少不必要的辐射。
CTPA 负责“定锤”：直接显示栓子形态、部位，并评估右心受累情况，是目前不可替代的确诊金标准。

危险分层与治疗干预

“治疗看危险”。根据血流动力学、PESI评分及右心功能进行四级分层，指导精准治疗。

高危

血流动力学不稳定

✓ 休克或持续低血压

✓ RV 功能障碍 (+)

✓ 心肌损伤 (+)

🚨 首选：溶栓 / 介入碎栓
基础：普通肝素 (UFH)

中高危

稳定, 但 sPESI ≥ 1

✗ 无休克

✓ RV 功能障碍 (+)

✓ 肌钙蛋白 (+)

👁️ 密切监测 + 抗凝
不推荐常规全身溶栓

中低危

稳定, sPESI ≥ 1

✗ 无休克

✗ RV异常/肌钙蛋白中仅一项(+)或均(-)

💊 常规住院抗凝
LMWH 或 DOACs

低危

稳定, sPESI = 0

✗ 无休克

✗ 通常无需评估 RV/标志物

🏠 考虑早期出院
家庭抗凝治疗 (DOACs)

⏳ 长期抗凝时程管理

  • ■ 标准疗程（至少3个月）：所有确诊 PE 患者的基础要求。
  • ■ 长期/无限期抗凝：针对第二次发生的非诱发性 PE，或存在持续性危险因素（如活动期癌症）。
  • ■ 远期并发症：警惕 CTEPH。若抗凝3个月后静息平均肺动脉压仍 ≥ 20 mmHg，需进一步干预（首选肺动脉内膜剥脱术）。

🤰 特殊人群：妊娠合并 PE

  • ! 诊断细节：D-二聚体会生理性增高，但阴性排除价值仍存。首选下肢静脉超声。
  • ✓ 金标准治疗：低分子肝素 (LMWH) 是妊娠期抗凝的首选。术前 12-24 小时停用。
  • ✗ 用药禁忌：禁用华法林（致畸风险）及 DOACs（缺乏安全性证据）。
